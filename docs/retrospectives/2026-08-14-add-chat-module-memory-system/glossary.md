# 术语：记忆系统

| 术语 | 定义 |
| --- | --- |
| 短期记忆 | 当前报错会话的进程内记忆：消息历史 + 对话上下文 + 滚动摘要，不落盘，新报错/新开会话即清空 |
| 长期记忆 | 跨会话持久保存的用户档案（`~/.errAnalyst/memory.json`），含三类偏好与常犯错误统计，参与自动分析 |
| 修复偏好 | 用户对修复补丁代码的长期偏好（改动范围、风格、策略） |
| 修复建议偏好 | 用户对纯文字修复指引的长期偏好（详略、结构、验证步骤） |
| 错误分析偏好 | 用户对错误分析结果的长期偏好（根因深度、解释粒度） |
| 常犯错误 | 用户反复出现的错误类型统计（errorType → 次数），行为事实而非声明 |
| 记忆配置 | `erranalyst memory config` 交互式管理长期记忆的入口（增删改、候选确认、开关），VS Code 侧注册同名命令 |
| 候选（candidate） | 仅观察 1 次的隐式偏好条目，不注入提示词，待用户在记忆配置中确认后转 active |
| 滚动摘要 | 历史被截断时由 LLM 惰性压缩的被丢弃消息，属于会话级压缩而非去情境化语义 |
