# 上下文捕获仅限项目文件

Status: accepted

报错上下文（LLM 的 Source Context、UI 的"源代码上下文"、对话自动加载文件、修复补丁的允许文件列表）只从项目文件收集：位于锚点（全部工作区文件夹，报错文件在工作区外且非系统目录时以其所在目录兜底）内、且不经过依赖/生成目录的文件；系统文件即使真实出现在调用栈中也排除，调用栈仅以列表形式保留。栈内无项目文件时，按"引用报错模块 → 活动编辑器文件 → 入口文件 → 最近修改"顺序猜测最多 3 个候选并标注"（猜测）"。配置文件经固定名单、代码引用、报错目录三层发现，敏感键值在读取时脱敏为"已配置 / 为空"。

原因：系统库文件不会出错，且会挤占 7000 字符预算，真实根因在项目代码或项目配置。后果：修复补丁只能落在项目文件上；LLM、UI 与对话看到同一份脱敏后的项目上下文。

例外：运行文件（用户实际运行的入口脚本）全量捕获且豁免字符预算，见 [ADR-0009](./0009-running-file-full-capture.md)。
