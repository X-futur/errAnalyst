# 0012 官方模型目录与模型校验

CLI 与配置向导此前接受任意非空模型名，无任何官方列表校验，且 DeepSeek/Kimi/Qwen 的模型数据在 `package.json`、`presets.ts`、`configWizard.html`、`bin/erranalyst` 四处硬编码并已互相漂移；DeepSeek 在 2026-07-24 退役 `deepseek-chat`/`deepseek-reasoner`，证明官方模型列表是变动的。我们决定：模型名称的唯一合法来源是各提供商的官方模型列表，写入时校验，并为每个预置提供商推荐速度最快的模型。

具体决策：

- **混合来源**：预置提供商（DeepSeek/Kimi/Qwen）使用随扩展发布的精选 chat 模型快照（单一共享文件 `src/shared/model-catalog.json`，带 `updatedAt` 与来源 URL，发版时人工更新）；自定义提供商写入时实时抓取 `GET {baseUrl}/models`，抓取失败回退连接测试，并在保存结果中明确标注。
- **预置严格白名单**：预置提供商的模型只能来自官方列表，列表外名称在写入时被拒绝，文案明确引导"可用自定义提供商添加"；自定义提供商路径允许非官方模型，但需通过连接测试并标注为"非官方模型"。
- **读取时只警告不阻断**：存量非法配置（含手改 `settings.json`、已下线模型）在激活/分析时弹警告但仍照常分析；`config show` 与向导中标红为"无效模型"；对已知退役别名提供"一键迁移到推荐模型"建议，不自动改写。
- **推荐模型**：快照内每个模型带静态速度档位（快速/均衡/更强，按官方 tier 命名判定，不做实测），每预置提供商标注 1 个"⚡ 推荐 · 速度优先"模型，向导下拉置顶默认选中，CLI 编号菜单置顶；预置路径不提供自由输入。
- **收敛数据源**：`presets.ts`、向导、CLI、`package.json` 默认值统一从单一快照读取，消灭四处拷贝漂移。

Status: accepted

## Consequences

- 快照会过期：官方新增模型到下一发版之间，预置路径无法选择该模型，用户只能走自定义提供商路径；每次发版必须更新快照与 `updatedAt`。
- CLI 的自定义提供商路径需要新增 `GET /models` 抓取与连接测试回退逻辑（当前 CLI 完全没有连接测试）。
- 升级后存量非法配置会出现读取警告，需要配合迁移引导（退役别名一键迁移）。
- `package.json` 的默认 providers 必须与快照保持一致，否则默认值绕过了白名单。
