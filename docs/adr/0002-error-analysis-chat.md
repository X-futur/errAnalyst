# 错误分析对话：对话上下文驱动问答与补丁生成

Status: accepted

ErrAnalyst 在修复建议卡片下方新增“错误分析对话”：AI 既解释根因、回答追问，也能基于会话内容生成修复补丁。补丁仍复用“逐处确认”流程，但白名单从分析时的 Source Context 扩为对话上下文（自动加载 + 用户新增、移除后失效），因为用户手动添加文件本身就是显式授权，且每处修改仍逐点确认后才写入。外部问题或无法确定时，对话只给操作建议，补丁返回空 `changes[]` 并附文字原因，避免把环境问题硬改成代码。

Considered Options: 对话只问答、不生成补丁（被否：用户需要根据会话内容直接产出补丁）；补丁白名单仅限 Source Context（被否：用户新增文件无法进入可修改范围）；流式输出（延后，接口层预留）。

Consequences: ADR-0001 中“AI 只能修改 Source Context 文件”的护栏据此扩展为“只能修改当前对话上下文中的文件”；LLM Provider 需要新增多轮对话接口；对话历史不落盘，只绑定当前报错视图。
